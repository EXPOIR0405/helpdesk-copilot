# 백로그

- 1단계(상담원 코파일럿) 이후 확장 계획
- 방향: 만들고 끝이 아니라 **계속 돌아가면서 관리되는 시스템**으로
  - 여러 모델을 같은 평가셋으로 비교하고 상황별로 고름
  - 사람이 부르지 않아도 문의를 받아 처리하고, 못 하는 건 맥락을 모아 사람에게 넘김
  - 비용·장애·품질을 계속 기록하고, 깨진 것과 고친 것을 남김
