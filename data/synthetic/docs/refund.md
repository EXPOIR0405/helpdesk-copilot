# 환불 정책

## 기본 원칙

- 환불 여부는 **결제 후 경과일**과 **시청 이력** 두 가지로 판단
- 시청 이력: 해당 결제 이후 콘텐츠를 1분 이상 재생한 기록 (예고편 제외)

| 조건 | 처리 |
|---|---|
| 결제 후 7일 이내, 시청 이력 없음 | 전액 환불 |
| 결제 후 7일 이내, 시청 이력 있음 | 환불 불가, 해지만 가능 |
| 결제 후 7일 경과 | 환불 불가, 해지만 가능 |

- 환불 불가인 경우에도 해지하면 남은 결제 기간 끝까지 이용 가능 (`cancel` 문서 참고)
- 부분 환불(남은 일수 일할 환불)은 하지 않음

## 예외: 전액 환불

- 같은 결제 주기에 중복 결제된 경우 → 중복 결제분 전액 환불, 시청 이력과 무관
- 회원이 요청하지 않은 요금제 변경 결제가 확인된 경우 → 해당 결제 전액 환불
- 계정 도용으로 인한 결제가 확인된 경우 → `account-security` 문서의 도용 처리 후 환불

## 예외: 서비스 장애 보상

- 시네웨이브 귀책의 전체 서비스 장애가 24시간 이상 연속될 때만 보상
- 보상은 환불이 아니라 장애 시간만큼 이용 기간 연장
- 개별 기기·네트워크 문제로 인한 재생 불가는 보상 대상 아님 (`playback-errors` 문서로 조치 안내)

## 인앱결제 환불

- 앱마켓 인앱결제는 앱마켓 환불 정책을 따름
- 상담원이 직접 환불 처리할 수 없음 → 앱마켓 고객센터로 환불 요청하도록 안내

## 환불 처리 기간

- 신용카드: 취소 후 3~5영업일 (카드사에 따라 다음 달 청구서에서 차감)
- 체크카드·간편결제: 취소 후 3~5영업일 안에 계좌 입금
- 휴대폰 소액결제: 결제한 달 안에는 결제 취소, 다음 달 이후에는 본인 명의 계좌로 환불

## 환불 후 처리

- 환불이 완료되면 해당 결제 기간의 이용권은 즉시 종료
- 다운로드한 콘텐츠도 즉시 재생 불가
