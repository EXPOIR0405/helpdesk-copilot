# 이용권·쿠폰·이벤트

## 종류

- 이용권: 정해진 기간(1개월, 3개월 등) 동안 결제 없이 이용하는 상품. 제휴사 혜택이나 선물로 지급
- 할인 쿠폰: 정기결제 금액을 깎아 주는 쿠폰

## 등록 방법

- 이용권·쿠폰 코드는 영문과 숫자 16자리
- 웹에서만 등록 가능: 마이페이지 > 이용권·쿠폰 등록
- 앱에서는 등록 불가 (앱마켓 정책)

## 적용 규칙

- 할인 쿠폰은 결제 1회에 1장만 적용, 중복 적용 불가
- 신규 가입 할인 쿠폰은 첫 결제에만 적용
- 이용권 사용 중에 정기결제를 신청하면 이용권 기간이 끝난 다음 날부터 결제 시작
- 인앱결제 가입자에게는 할인 쿠폰 적용 불가 (이용권은 인앱결제 해지 후 사용 가능)

## 유효기간

- 이용권·쿠폰마다 등록 유효기간이 있음. 코드 발급 안내문에 표시
- 유효기간이 지난 코드는 복구·연장 불가
- 등록한 이용권은 등록 즉시 이용 기간 시작

## 이벤트

- 이벤트 참여 조건과 경품 지급 일정은 각 이벤트 페이지의 공지 기준으로 안내
- 이벤트 페이지에 없는 내용(당첨 여부 사전 확인, 경품 교환)은 안내 불가
- 경품 미수령 문의는 이벤트 담당에게 이관
