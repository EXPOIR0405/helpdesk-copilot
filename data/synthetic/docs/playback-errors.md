# 재생 오류 조치

## 공통 1차 조치

- 앱 최신 버전 업데이트
- 앱 완전 종료 후 재실행, 기기 재부팅
- 다른 콘텐츠도 재생되지 않는지 확인 → 특정 콘텐츠만 안 되면 콘텐츠 문제, 전부 안 되면 기기·네트워크 문제

## 오류 코드별 조치

### CW-1001 네트워크 연결 오류

- 원인: 인터넷 연결 불안정, 속도 부족
- 권장 속도: HD 3Mbps, FHD 5Mbps, 4K 25Mbps 이상
- 조치: 공유기 재시작, 모바일 데이터와 Wi-Fi 전환해서 재시도

### CW-2003 콘텐츠 보호(DRM) 오류

- 원인: 기기·브라우저가 콘텐츠 보호 기술을 지원하지 않음, 외부 모니터가 HDCP 미지원
- 조치: 앱·브라우저 업데이트, 외부 모니터 연결 해제 후 재생, 화면 녹화·미러링 앱 종료
- 루팅·탈옥 기기에서는 재생 불가

### CW-3010 동시 시청 한도 초과

- 원인: 요금제의 동시 시청 수 초과
- 조치: `account-sharing` 문서의 동시 시청 수 기준으로 안내

### CW-4040 콘텐츠 이용 불가

- 원인: 판권 종료로 내려간 콘텐츠, 또는 국내에서만 서비스되는 콘텐츠를 해외에서 재생 시도
- 조치: 판권 종료 여부는 `content-schedule` 문서 기준으로 안내
- 해외 재생 가능 여부에 대한 별도 정책 문서는 없음

### CW-5000 서버 오류

- 원인: 시네웨이브 서버 문제
- 조치: 공지사항의 장애 공지 확인 안내
- 같은 오류가 30분 이상 반복되면 기술지원 담당에게 이관 (고객 기기 정보, 발생 시각, 오류 코드 기록)

## 화질 관련 문의

- 4K 재생 조건: 프리미엄 요금제 + 4K 지원 기기·앱 + 25Mbps 이상 속도 → 셋 중 하나라도 빠지면 FHD 이하로 재생
- 모든 콘텐츠가 4K로 제공되지는 않음. 콘텐츠 상세 화면에 4K 표시가 있는 작품만 해당
- 네트워크 상태에 따라 화질이 자동 조절됨. 설정 > 재생 화질에서 고정 가능

## 보상 문의

- 개별 기기·네트워크 문제는 보상 대상 아님
- 전체 서비스 장애 보상 기준은 `refund` 문서 참고
