# 콘텐츠 공개·종료 안내

## 공개 일정 안내 원칙

- 공식 공지사항이나 콘텐츠 상세 화면에 게시된 일정만 안내
- 공지되지 않은 공개일, 다음 시즌 제작 여부는 추측해서 안내하지 않음
- 응대 문구 예: "현재 공지된 일정이 없습니다. 확정되면 공지사항과 알림으로 안내됩니다."

## 오리지널 콘텐츠

- 시네웨이브 오리지널 시리즈 신규 회차는 매주 금요일 오후 6시 공개가 기본
- 작품별로 다를 수 있으므로 상세 화면의 공개 일정 우선

## 방송 연계 콘텐츠

- TV 방송과 함께 서비스하는 콘텐츠는 본방송 종료 1시간 뒤 업로드가 기본
- 방송사 사정으로 지연될 수 있음. 지연 사유는 안내하지 않음

## 판권 종료(공개 종료)

- 판권 종료 30일 전부터 상세 화면에 "공개 종료 예정" 표시와 종료일 노출
- 종료 후에는 찜 목록에 남아 있어도 재생 불가 (오류 코드 CW-4040)
- 종료된 콘텐츠의 재공개 여부는 안내 불가

## 콘텐츠 요청

- 고객이 원하는 작품 추가를 요청하면 상담 기록에 작품명을 남겨 콘텐츠 담당에게 전달
- 반영 여부와 결과는 고객에게 따로 회신하지 않는다고 안내
