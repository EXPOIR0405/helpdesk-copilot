# 성인 인증과 시청 등급 설정

## 성인 인증

- 청소년 관람불가 콘텐츠를 보려면 성인 인증 필요
- 인증 방법: 휴대폰 본인인증
- 인증은 1년간 유효. 1년이 지나면 재인증 요청
- 성인 인증 명의와 결제자 명의가 달라도 됨
- 인증은 계정 단위로 적용되지만, 프로필별 시청 등급 제한이 우선

## 프로필별 시청 등급 제한

- 프로필마다 볼 수 있는 최대 등급 설정 가능: 전체, 12세, 15세, 청소년 관람불가
- 키즈 프로필은 12세 이하 등급만 노출되며 변경 불가
- 설정 경로: 마이페이지 > 프로필 관리 > 시청 등급

## 프로필 잠금

- 프로필마다 4자리 PIN 잠금 설정 가능
- PIN을 잊은 경우 계정 비밀번호를 입력해 재설정
- 상담원이 PIN을 확인하거나 대신 해제할 수 없음

## 청소년 보호

- 만 19세 미만 명의로는 성인 인증 불가
- 보호자가 자녀의 시청을 제한하려면 키즈 프로필 또는 프로필 잠금을 안내
