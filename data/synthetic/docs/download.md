# 다운로드(오프라인 저장)

## 요금제별 다운로드

- 베이직: 다운로드 불가
- 스탠다드: 기기 2대까지
- 프리미엄: 기기 4대까지
- 다운로드는 모바일·태블릿 앱에서만 가능. PC 웹과 TV 앱은 불가

## 저장 한도와 보관 기간

- 기기당 최대 100편 저장
- 저장한 콘텐츠는 저장일로부터 30일간 보관
- 한 번 재생을 시작하면 48시간 안에 시청 완료 필요, 이후 자동 만료
- 만료된 콘텐츠는 인터넷 연결 후 다시 다운로드 가능

## 오프라인 인증

- 다운로드 콘텐츠를 계속 보려면 30일에 한 번 이상 인터넷에 연결해 계정 확인 필요

## 다운로드 불가 콘텐츠

- 일부 콘텐츠는 판권 조건상 다운로드 불가. 상세 화면에 다운로드 버튼이 없음
- 판권 종료 예정 콘텐츠는 종료일에 다운로드본도 재생 불가

## 해지·환불 시

- 해지: 이용 기간 종료 시점에 다운로드본 재생 불가
- 환불: 환불 완료 즉시 재생 불가
