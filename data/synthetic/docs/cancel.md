# 해지 안내

## 해지의 의미

- 해지는 **다음 정기결제를 멈추는 것**
- 해지해도 이미 결제한 기간 끝까지 정상 이용 가능
- 해지는 환불이 아님. 환불 조건은 `refund` 문서 기준

## 해지 절차

- 웹: 마이페이지 > 이용권 관리 > 정기결제 해지
- 앱마켓 인앱결제 가입자: 앱마켓의 구독 관리 메뉴에서 해지 (시네웨이브 웹에서는 해지 불가)
- 해지 완료 시 가입 이메일로 해지 확인 메일 발송

## 해지 취소

- 이용 기간이 끝나기 전이라면 해지 취소 가능
- 웹: 마이페이지 > 이용권 관리 > 해지 취소
- 해지 취소 시 기존 결제일에 정상 결제

## 해지 후 데이터

- 시청 기록, 찜 목록, 프로필은 이용 종료 후 12개월 보관
- 12개월 안에 다시 구독하면 그대로 복원
- 다운로드한 콘텐츠는 이용 기간 종료 시점에 재생 불가

## 해지와 회원 탈퇴의 차이

| 구분 | 해지 | 회원 탈퇴 |
|---|---|---|
| 정기결제 | 중단 | 중단 |
| 남은 이용 기간 | 끝까지 이용 | 즉시 소멸 |
| 시청 기록·찜 | 12개월 보관 | 즉시 삭제 |
| 재가입 | 같은 계정으로 재구독 | 새 계정 가입 필요 |

- 남은 기간이 있는데 탈퇴를 원하면 남은 기간이 소멸된다는 점을 반드시 안내
- 탈퇴 후 30일 동안 같은 이메일로 재가입 불가
